# TikTok Lite 포인트 파머 (AutoX.js)

TikTok Lite에서 **시청 → 타이머 수령 → 광고보기 → 좋아요 수령 → 출석체크**를
자동으로 반복해 포인트를 적립하는 안드로이드 자동화 앱입니다.
플로팅 제어판의 **[시작]** 한 번으로 동작하며, 켜두면 알아서 포인트를 쌓습니다.

> ⚠️ **개인 편의용 자동화입니다.** TikTok 이용약관상 자동화가 제한될 수 있으며,
> 계정 정지·포인트 회수 등의 위험이 있습니다. **판매·사용 전 반드시
> [`구매전_필독.md`](./구매전_필독.md)(고지 및 면책 동의서)를 읽고 구매자에게 동의를
> 받으세요.**

---

## 제품 구성

| 파일 | 역할 |
|------|------|
| `main.js` | 진입점 — 플로팅 제어판(시작/정지/좌표설정) |
| `core.js` | 자동화 엔진 — 플로우, 오류 복구, 무한 파밍 루프, 좌표 캘리브레이션 |
| `config.js` | 설정 — 기기 저장소에 영구 저장(좌표설정 결과 자동 저장) |
| `project.json` | APK 빌드 descriptor(앱 이름/패키지/권한) |

## 주요 기능

- **원클릭 실행**: 제어판 [시작] 버튼 하나로 전체 플로우 자동 진행
- **무한 파밍 모드**: 영상 시청으로 타이머를 충전하며 20분마다 수령을 반복 → 켜두면 계속 적립
- **자동 복구**: 앱이 튕기거나 다른 화면으로 벗어나면 자동으로 재실행/복귀
- **탭 좌표설정**: [좌표설정] 버튼 → 화면을 탭하는 것만으로 버튼 위치 등록(픽셀 계산 불필요)
- **설정 영구 저장**: 좌표/옵션이 기기에 저장되어 재실행해도 유지
- **로그 기록**: 화면 로그 + `/sdcard/ttl_farmer.log` 파일로 문제 추적

## 동작 흐름 (의뢰 1~12)

1. TikTok Lite 실행
2. 영상 화면 팝업(출석체크/이벤트) 종료
3. 우측 중간 하트 → 지정 시간만큼 스크롤 시청(중간 팝업 자동 닫기)
4. 좌측 하단 두번째 포인트 버튼
5. 포인트 화면의 (이벤트)팝업 종료
6. **20분마다** 타이머 → 받기
7. 광고보기
8. 30초 대기 → 좌측 상단 p
9. 영상 좋아요 → 받기
10. 뒤로가기
11. 출석체크
12. 앱 종료 *(무한 파밍 모드에서는 종료 대신 계속 파밍)*

## 설치 & 최초 설정 (구매자용)

### 1) AutoX.js 설치 & 권한
- AutoX.js 설치
- **접근성 서비스 ON**: 설정 → 접근성 → AutoX.js → 사용
- **다른 앱 위에 표시(오버레이) ON**: 설정 → 앱 → AutoX.js → 다른 앱 위에 표시 허용

### 2) 스크립트 넣고 실행
- `main.js`, `core.js`, `config.js`, `project.json`을 AutoX.js 프로젝트 폴더에 넣기
- `main.js` 실행 → 화면에 제어판이 뜸

### 3) 좌표설정 (최초 1회, 필수)
- TikTok Lite를 각 버튼이 보이는 화면에 두고
- 제어판 **[좌표설정]** 누르기 → 안내 문구가 뜨는 순서대로 해당 위치를 **탭**
  - ① 팝업 닫기 X → ② 하트 → ③ 포인트 버튼 → ④ 타이머 → ⑤ 좌측상단 p → ⑥ 영상 좋아요 → ⑦ 출석체크
- 완료되면 자동 저장됨(다음부터 생략 가능)

### 4) 시작
- **[시작]** 누르면 파밍 시작. 폰을 켜둔 채 두면 계속 적립됩니다.
- 멈추려면 **[정지]**.

## 원클릭 / 앱 형태로 배포

- **홈 화면 바로가기**: AutoX.js에서 스크립트 길게 눌러 "바로가기 생성" → 홈 아이콘 1탭 실행
- **독립 APK**: AutoX.js "APK 빌드"로 `project.json` 기반 독립 앱 생성(앱 이름/아이콘 지정 가능) → 구매자에게 APK만 전달

## 설정 커스터마이즈 (`config.js`)

| 항목 | 설명 |
|------|------|
| `mode` | `"farm"`(무한 파밍, 기본) / `"once"`(1~12 한 바퀴 후 종료) |
| `timing.betweenCycleMs` | 타이머 수령 간격(기본 20분) |
| `timing.scrollIntervalMs` | 영상 1개당 시청 시간(기본 20초) |
| `timing.afterAdWatch` | 광고 후 대기(기본 30초) |
| `humanize` | 대기시간에 랜덤 부여(사람처럼) |
| `texts.*` | 폰 언어에 맞는 버튼 문구 후보 |

## 문제 해결

- **버튼이 엉뚱한 곳을 누름** → [좌표설정] 다시 진행
- **텍스트 못 찾음** → `config.js`의 `texts`에 실제 화면 문구 추가
- **앱이 안 켜짐** → `appName` / `packageCandidates` 확인
- **광고가 30초보다 김** → `timing.afterAdWatch` 늘리기
- **화면 꺼짐** → `keepScreenOn: true`(기본) 유지, 절전 예외 등록 권장
- 상세 로그: `/sdcard/ttl_farmer.log`

## 🛡️ 안전 사용 가이드 (계정 정지 위험 낮추기 — 구매자 안내용)

자동화 탐지·차단 위험을 **완전히 없앨 수는 없지만**, 아래를 지키면 위험이 줄어듭니다.

- **계정당 기기 1대** — 한 폰에서 여러 계정 돌리지 마세요(기기 지문으로 즉시 의심).
- **개별 IP 사용** — 공유 WiFi로 여러 대 동시 사용 금지. 폰별 **LTE/5G(개별 IP)** 권장.
- **사람처럼 쉬기** — 24시간 무중단 금지. `humanize`(기본 켜짐) 유지로 딜레이·궤적 랜덤화.
- **CAPTCHA/보안인증이 뜨면 즉시 멈춤** — 프로그램이 자동 정지하고 알립니다. **직접 인증**한
  뒤 다시 시작하세요. 절대 무리하게 재시도하지 마세요.
- **의심 징후(포인트 미적립·잦은 인증 요구)가 보이면 사용을 중단**하세요.
