# TikTok Lite 자동 포인트 적립 (AutoX.js)

TikTok Lite에서 시청/하트/타이머/광고보기/출석체크를 **원클릭**으로 자동 실행해
포인트를 적립하는 AutoX.js 스크립트입니다. **접근성 서비스(Accessibility Service)** 로
버튼 텍스트를 찾아 누르고, 못 찾으면 **좌표**로 폴백합니다.

> ⚠️ 개인 편의용 자동화입니다. TikTok의 이용약관상 자동화가 제한될 수 있으니
> 본인 책임하에 사용하세요.

## 파일 구성

| 파일 | 설명 |
|------|------|
| `config.js` | **여기만 수정하면 됨.** 앱 패키지명, 반복 횟수, 대기시간, 버튼 텍스트, 좌표(화면 비율) |
| `main.js` | 실행 스크립트 (수정 불필요) |

## 설치 & 실행

1. **AutoX.js 설치** (Play스토어 또는 GitHub 배포판)
2. **접근성 서비스 켜기**: 설정 → 접근성 → AutoX.js → 사용
3. `config.js`, `main.js`를 AutoX.js 스크립트 폴더에 넣기
4. `config.js`를 자기 폰에 맞게 보정 (아래 참고)
5. AutoX.js에서 `main.js` 실행

### 원클릭으로 만들기
- **홈 화면 바로가기**: AutoX.js에서 스크립트 길게 눌러 **바로가기 생성** → 홈 화면 아이콘 한 번으로 실행
- **위젯**: AutoX.js 위젯으로 등록
- **APK로 패키징**: AutoX.js의 "APK 빌드" 기능으로 독립 실행 앱 생성 가능

## 동작 흐름 (요청 1~12)

1. TikTok Lite 실행
2. 영상 화면 팝업(출석체크/이벤트) 종료
3. 우측 중간 하트 → **지정 시간만큼 스크롤 시청** (중간 팝업 자동 닫기)
4. 좌측 하단 두번째 포인트 버튼
5. 포인트 화면의 (이벤트)팝업 종료
6. **20분마다** 타이머 → 받기
7. 광고보기
8. 30초 대기 → **좌측 상단 p**
9. 영상 좋아요 → 받기
10. 뒤로가기
11. 출석체크
12. 앱 종료

### 반복 동작 (`config.maxCycles`)
- `1` (기본): 1~12를 **한 바퀴** 돌고 앱 종료
- `2` 이상: 6~10 적립 사이클을 **20분 간격**으로 그 횟수만큼 반복한 뒤, 11(출석)·12(종료) 수행

## config.js 보정 방법 (가장 중요)

실기기마다 해상도·버튼 위치·언어가 달라서 **초기 좌표값은 반드시 보정**해야 합니다.

### 1) 패키지명 확인
`설정 > 앱 > TikTok Lite`에서 패키지명을 확인하거나, `config.js`의
`packageCandidates` 후보를 그대로 두면 순서대로 자동 시도합니다.

### 2) 좌표 보정 (화면 비율 0.0~1.0)
- AutoX.js 개발자 옵션에서 **"포인터 위치"** 표시를 켭니다.
- 원하는 버튼을 눌러 픽셀 좌표를 확인합니다.
- 비율 = `픽셀값 / 화면크기`
  - 예) 화면 폭 1080, 버튼 x=1000 → `x: 0.93`
  - 예) 화면 높이 2400, 버튼 y=1200 → `y: 0.50`

보정할 좌표: `popupClose`, `heart`, `pointButton`, `timer`, `topLeftP`, `videoLike`, `attendanceCheck`

### 3) 시청 시간
`timing.watchDurationMs`(총 시청 시간)과 `timing.scrollIntervalMs`(영상 1개당 시청 시간)로
스크롤 시청을 조절합니다. 기본 = 5분 동안, 20초마다 다음 영상으로.

### 4) 버튼 텍스트
폰 언어에 맞게 `texts`의 배열을 수정하세요. 여러 후보를 넣으면 순서대로 찾습니다.

## 문제 해결

- **버튼이 안 눌림** → `config.js`의 해당 좌표를 실측값으로 보정
- **텍스트를 못 찾음** → `texts`에 실제 화면 문구 추가
- **앱이 안 켜짐** → `appName` / `packageCandidates` 확인
- **광고가 30초보다 김** → `timing.afterAdWatch` 값 늘리기
- **시청 중 스와이프가 어색** → `swipeToNextVideo()`의 y1/y2 비율 또는 `scrollIntervalMs` 조정
- **앱 완전 종료 필요** → `closeApp()`은 홈으로 내림(백그라운드). 강제 종료는 루팅/추가 권한 필요
- 실행 로그는 AutoX.js 콘솔과 화면 토스트로 확인 가능
