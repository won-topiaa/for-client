# 📈 이평선 레이더 (stock-ma-analyzer)

종목을 검색하고 **분석** 버튼을 누르면, **일봉·주봉·월봉**별로 그동안 **가장 자주,
믿을 만하게 지지/저항 역할을 해온 이동평균선을 2~3개씩** 백테스트로 찾아
차트에 그려주는 웹 프로그램입니다.

- **무료 시세 데이터** 기본 사용 — API 키·IP 등록 불필요 (국내: FinanceDataReader/네이버 · 미국: Stooq→yfinance→FDR 3중 폴백)
- 국내 전 종목 이름 검색 + 미국 종목 한글 이름 검색(예: "엔비디아"→NVDA, ~290개 사전) · 티커 직접 입력
- 후보 이평선: 일봉 `5/10/20/50/60/100/120/200/240`, 주봉 `5/10/20/30/52/60/104`, 월봉 `3/6/12/24/36/60` (설정 변경 가능)
- 추천 이평선을 캔들차트 위에 오버레이 + 지지/저항 이벤트 마커 표시
- 전체 후보의 성적표(터치·지지성공·저항성공·돌파·성공률·점수) 제공

> ⚠️ 과거 데이터 통계이며 투자 권유가 아닙니다. 과거에 잘 지켜진 이평선이
> 미래에도 지켜진다는 보장은 없습니다.

---

## 1. 빠른 시작

```bash
cd stock-ma-analyzer
pip install -r requirements.txt
python -m uvicorn app.server:app --port 8000
# 브라우저에서 http://localhost:8000 접속
```

기본값은 **무료 시세 공급자**입니다 — 국내는 FinanceDataReader(네이버 소스),
미국은 Stooq(무키·데이터센터 친화적)를 먼저 쓰고 yfinance→FDR 순으로 폴백합니다.
API 키도, IP 등록도 필요 없어서 그대로 실행하면 실제 데이터로 동작하고,
**공개 배포에도 그대로 쓸 수 있습니다.**

## 데이터 공급자 선택 (`MA_PROVIDER` 환경변수 또는 config.json `provider`)

| 값 | 설명 |
|---|---|
| `auto`(기본)/`free` | 무료 시세 (국내 FDR/네이버 · 미국 Stooq→yfinance→FDR). 키·IP 불필요, 공개 배포 가능 |
| `toss` | 토스증권 Open API (키 필요, 서버 IP를 토스 허용목록에 등록해야 함) |
| `sample` | 시드 고정 합성 데이터 (오프라인 데모/테스트용) |

`sample` 모드에서 실제 CSV 가 있으면 `data/종목코드.csv` 로 넣어 분석할 수 있습니다
(컬럼: `date,open,high,low,close,volume`).

## 2. (선택) 토스증권 Open API 연결

> 무료 공급자로 충분하며, 토스는 **개인 투자용**이라 공개 사이트에서 다수에게
> 데이터를 재배포하는 용도로는 부적합합니다(약관·요청한도·IP 제약). 아래는
> 본인이 개인적으로 토스 실시간 데이터를 쓰고 싶을 때만 참고하세요.

1. [토스증권 Open API](https://corp.tossinvest.com/ko/open-api) 에서 사용 신청 후
   `client_id` / `client_secret` 발급
2. 설정 방법 (둘 중 하나):
   - 환경변수: `TOSS_CLIENT_ID=... TOSS_CLIENT_SECRET=... python -m uvicorn app.server:app`
   - 또는 `config.example.json` 을 `config.json` 으로 복사해 키 입력
3. 키를 넣은 뒤 `provider: "toss"` (또는 `MA_PROVIDER=toss`)로 설정해야 토스 공급자로
전환됩니다 — 키만 넣는 것으로는 자동 전환되지 않습니다.

### 공식 스펙 반영 상태

토스증권 공식 OpenAPI 스펙(v1.1.5) 기준으로 기본값이 맞춰져 있습니다:

- 토큰: `POST /oauth2/token` (form, client_credentials)
- 캔들: `GET /api/v1/candles?symbol=&interval=1d&count=&before=`
  (1회 최대 200개, `nextBefore` 커서로 과거 페이지네이션, 수정주가 기본 적용)
- 종목 정보: `GET /api/v1/stocks?symbols=005930,AAPL`

알아둘 것 두 가지:

1. **공식 API 에는 "이름 검색"이 없습니다** (`/api/v1/stocks` 는 코드 전용).
   그래서 이름 검색은 내장 주요 종목 사전(약 90개, `app/providers/kr_symbols.py`)
   으로 코드를 찾은 뒤 API 로 실제 종목명을 확정합니다. 사전에 없는 종목은
   **6자리 코드**(예: `042670`)나 **미국 티커**(예: `AAPL`)를 직접 입력하세요.
   전 종목 이름 검색을 원하면 KRX 정보데이터시스템(data.krx.co.kr)에서 상장종목
   목록을 받아 `data/symbols.csv` (컬럼: `symbol,name[,market]`)로 저장하면
   자동으로 검색에 포함됩니다.
   - **미국 종목은 한글 이름으로도 검색**됩니다 — `app/data/us_stocks.csv`
     (컬럼: `ticker,exchange,name_ko,name_en,aliases`)에 대표 종목 ~290개를
     넣어 두었습니다. 예: "애플"→AAPL, "엔비디아"→NVDA, "슈드"→SCHD.
     엑셀로 열어 자유롭게 추가/수정하면(‘#’ 줄은 주석) 서버 재시작 없이
     반영됩니다. 사전에 없어도 티커(예: `AAPL`)를 직접 입력하면 분석됩니다.
2. **봉 단위는 분봉/일봉만 제공**됩니다. 주봉·월봉은 일봉을 자동으로
   리샘플링(주: 월~금 집계, 월: 월별 집계)해서 분석합니다.

스펙이 향후 바뀌면 `config.json` 의 `toss` 섹션에서 경로·파라미터명을
재정의할 수 있고, 응답 파싱은 필드명 별칭 기반(관용 파서)이라 구조가 조금
달라져도 대부분 자동으로 해석됩니다. 예전 버전 `config.json` 의 기본값
(`/api/v1/market/candles` 등)은 실행 시 자동으로 새 스펙으로 이관됩니다.

## 3. 백테스트 기간 — 무엇을 권장하나

**전체 기간보다는 "타임프레임별로 다른 기간 + 최근 가중"을 권장하며, 그렇게 기본값을 설정했습니다.**

| 타임프레임 | 기본값 | 근거 |
|---|---|---|
| 일봉 | **최근 3년** | 이평선 지지/저항은 그 종목을 매매하는 참여자 구성(수급 레짐)의 산물이라 영구적이지 않습니다. 10년 전 데이터까지 동일 가중으로 섞으면 지금은 무의미한 레짐의 통계가 노이즈로 들어옵니다. 3년(약 750봉)이면 MA240까지 충분한 표본이 나오면서도 현재 레짐 위주로 측정됩니다. |
| 주봉 | **최근 7년** | 주봉은 봉 수가 적어(1년 = 52개) 3년으로는 MA104 같은 장기선의 터치 표본이 부족합니다. 7년(약 364봉)이면 표본과 최신성의 균형이 좋습니다. |
| 월봉 | **전체 기간** | 월봉은 20년 치가 있어도 240개뿐입니다. 자르면 장기선 통계가 불가능하므로 전체를 쓰는 것이 맞습니다. |

여기에 더해 모든 타임프레임에서 **최근 가중(지수 반감기)** 을 적용합니다.
분석 구간의 1/3을 반감기로 하여 최근 사건이 오래된 사건보다 큰 가중치를
받습니다. 즉 "전체 기간을 쓰되 옛날 데이터의 발언권을 줄이는" 절충이
월봉에 자동 적용되고, 일봉·주봉도 구간 내에서 최신 흐름이 우선됩니다.

UI에서 기간을 자유롭게 바꿀 수 있고, **0을 입력하면 전체 기간**으로 돌립니다.
상장한 지 얼마 안 된 종목은 데이터가 짧아 장기선이 "데이터 부족"으로 표시될
수 있습니다 (그 자체가 유의미한 정보입니다).

## 4. 분석 방법 (알고리즘)

차트에 그려진 단순이동평균(SMA)과 가격의 상호작용을 다음 규칙으로 측정합니다.

1. **터치**: 봉의 저가~고가 범위가 MA 주변 허용 밴드에 닿으면 터치.
   밴드 폭은 `max(ATR(14) × 0.5, 종가 × 0.15%)` — 종목 변동성에 자동 적응.
2. **에피소드**: 2봉 이내 연속 터치는 하나의 사건으로 묶음 (한 번의 눌림을
   여러 번으로 중복 집계하지 않기 위함).
3. **방향**: 직전 5봉 종가가 MA 위였으면 "지지 시험", 아래였으면 "저항 시험".
4. **판정** (에피소드 시작 후 일봉 10봉 / 주봉 8봉 / 월봉 6봉 안에):
   - **성공(반등)**: 종가가 MA에서 원래 방향으로 ATR×1.0 이상 되돌아감
   - **실패(돌파)**: 종가가 MA 반대편으로 ATR×1.0 이상 넘거나, 3봉 연속으로
     터치 밴드 **바깥** 반대편에서 마감 (밴드 안에서 MA 를 사이에 두고
     오르내리는 노이즈는 돌파로 치지 않음)
   - 어느 쪽도 아니면 **미확정** (성공률 계산에서 제외)
5. **점수** = `가중 성공률의 Wilson 신뢰하한 × log(1 + 가중 성공 횟수)`
   - Wilson 신뢰하한: "3번 중 3번 성공(100%)"이 "20번 중 15번 성공(75%)"을
     이기지 못하게 표본 크기를 반영
   - log 항: 자주 작동한 이평선에 가점하되 횟수가 질을 압도하지 않게 압축
6. **추천**: 점수순 상위에서, 기간이 20% 이내로 비슷한 이평선(예: 100과 120)은
   상위 하나만 남기고 2~3개 선정. 최소 터치 횟수(일 5·주 4·월 3) 미달이면
   "표본 부족" 표시와 함께 참고용으로만 노출.

미래 참조(lookahead) 없음 — 판정은 해당 사건 이후의 봉만 봅니다.

## 6. 사이트로 배포 (Render — 무료, GitHub 푸시 시 자동 업데이트)

기본 공급자가 **무료 시세** 라 **API 키도, IP 등록도
필요 없어** 공개 사이트로 그대로 배포됩니다. 저장소 루트에 `render.yaml` 준비됨.

1. render.com 가입 (GitHub 계정으로 로그인)
2. **New → Blueprint** → 이 GitHub 저장소 연결 → 브랜치 선택
3. 환경변수 (선택):
   - `SITE_PASSWORD`: 설정하면 접속 시 비밀번호를 요구 (비공개로 쓰고 싶을 때).
     **완전 공개**로 열려면 비워두면 됩니다.
   - `DATABASE_URL`: 회원 계정을 영구 보관할 외부 Postgres 연결 문자열
     (예: Neon 무료 — 설정 절차는 `docs/DEPLOY.md`). 없으면 로컬 SQLite 로
     동작하지만 Render 무료 플랜에서는 재배포 시 계정이 사라집니다.
   - `TOSS_*` 는 무료 공급자를 쓰면 **불필요** (넣어도 무시됨).
4. 배포가 끝나면 `https://<이름>.onrender.com` 주소가 생깁니다
5. 이후 이 브랜치에 푸시할 때마다 **자동으로 재배포**됩니다

무료 플랜 특성: 15분 동안 접속이 없으면 잠들었다가 다음 접속 때 깨어나는 데
30초~1분 걸립니다. 실제 시세 호출은 30분 캐시 + 동시요청 합치기로 보호되어
소스에 부담을 주지 않습니다. 야후로 가는 요청은 전역 최소 간격(0.35초)을
지켜 데이터센터 IP 의 요청 제한(429)을 피하고, 스캔 초반 종목이 전부
실패하면(소스 전면 장애) 즉시 오류를 표시하고 1분 뒤 자동 재시도합니다.

> 공개 배포 시 참고: 무료 소스(Yahoo/네이버 등)도 대량 상업적 재배포는 제한될
> 수 있습니다. 취미·소규모 용도로 쓰고, 트래픽이 커지면 캐시 TTL 을 늘리세요.

## 7. 테스트

```bash
python -m pytest tests/ -q
```

지지 반등/돌파 판정, 특정 MA에 지지 패턴을 심은 합성 데이터에서 그 MA가
상위 추천되는지, lookahead 부재, 리샘플링 정확성, 토스 응답 파서 관용성,
API 통합까지 검증합니다.

## 8. 차트 패턴 스크리너 — 매칭 · 자동 탈락 기준

`/patterns` 페이지는 유동성 상위 유니버스(국내: 거래대금 상위 300 − 시총 상위
30 초대형주, 미국: S&P500 − 메가캡)를 주기적으로 스캔해 패턴별 상위 매칭을
보여준다. **패턴을 이탈·무효화한 종목은 다음 스캔(최대 30분)에서 자동
탈락**한다. 탈락 기준은 아래 문헌을 근거로 정했다.

| 패턴 | 자동 탈락(무효화) 기준 | 근거 |
|---|---|---|
| 헤드앤숄더 (역헤드앤숄더는 대칭) | 넥라인 이탈(완성) **시점**을 추적: ① 종가가 머리를 넘어 회복 → busted 무효 ② 완성 후 10봉 초과 경과 → 신호 소진 ③ 완성 후 종가가 넥라인 반대편으로 2% 초과 회복 → 실패 돌파 (정상 되돌림은 넥라인 부근까지) ④ 이탈 방향 5% 초과 진행 → 진입 늦음. 미완성 상태는 넥라인 +6% 이내 접근만 표시 | Bulkowski(2005) busted 정의·5% 룰·되돌림 평균 ~10일 · Lo·Mamaysky·Wang(2000): completion 정의, 정보력은 완성 직후 집중 |
| 삼각수렴 | ① 종가가 추세선 밖 1 ATR 초과 → 돌파 완료로 제외 ② 돌파 없이 꼭짓점까지 85% 초과 수렴 → 예측력 소멸 | Bulkowski(2005): 돌파는 평균 꼭짓점 거리의 73~75% 지점에서 발생, 꼭짓점 도달 시 실패 경향 |
| 컵앤핸들 | ① 핸들 조정이 컵 깊이의 50% 또는 15% 초과 ② 테두리 −15% 아래 붕괴 ③ 테두리 +5% 초과 상승(추격 구간) | O'Neil 「How to Make Money in Stocks」: 핸들은 컵 상반부, 매수는 피벗 +5% 이내 |
| 와인스타인 초기 2단계 | ① 종가가 30주선 아래 ② 돌파선 −3% 초과 되밀림(실패 돌파) ③ 돌파선 +25% 초과 확장 | Weinstein(1988): 30주선 이탈 = 매도 규칙, 돌파는 지지로 유지되어야 함 |

구현은 `app/patterns.py` 의 각 탐지기 안에 있으며(스캔마다 전체 재평가라
별도 상태 관리 없이 기준 미달 종목이 자연 탈락), 각 기준은
`tests/test_patterns.py` 의 "패턴 이탈(무효화)" 테스트로 회귀 보호된다.

## 8.5 오늘의 지지선 터치 (`/touches`)

이평선 레이더 엔진을 유니버스 전체에 거꾸로 적용한 데일리 스크리너.
종목마다 일봉 3년을 백테스트해 추천(qualified) 이평선을 찾고, 그중
**오늘 저가가 그 선의 허용 밴드(max(0.5×ATR14, 종가의 0.15%) — 엔진과 동일
기준)까지 내려왔고 종가가 밴드 아래로 확정 이탈하지 않은** 종목만 보여준다.
직전 20봉 평균이 선 위(지지로 접근하는 문맥)여야 하고, **5일선은 제외**하며
(단기선은 지지선 신뢰도가 낮음) **지지 성공(반등) 3회 이상 · 지지 성공률(최근
가중) 60% 이상**인 '검증된 선'만 인정. 정렬은 선의 신뢰 점수(지지 성공률
Wilson 하한 × log(1+가중 성공)) 순.
이 페이지는 **회원 전용(무료)** — 이메일 가입/로그인(`/login`) 후 이용하며,
계정은 `DATABASE_URL` 로 연결한 외부 Postgres(예: Neon 무료)에 영구 보관된다.
설정 절차는 `docs/DEPLOY.md` 참고.
구현: `app/touch_scan.py` (`BaseScanner` 공유 — 30분 캐시·쿨다운·SWR 동일).

## 9. 참고 문헌

스크리너의 매칭·탈락 기준과 유니버스 설계가 근거한 자료의 정식 서지사항:

1. Lo, A. W., Mamaysky, H., & Wang, J. (2000). Foundations of Technical
   Analysis: Computational Algorithms, Statistical Inference, and Empirical
   Implementation. *The Journal of Finance*, 55(4), 1705–1765.
   https://doi.org/10.1111/0022-1082.00265
   — 기하학적 패턴 탐지 방법론, 패턴 정보력은 완성 직후 집중 (H&S 탈락 기준)
2. Han, Y., Yang, K., & Zhou, G. (2013). A New Anomaly: The Cross-Sectional
   Profitability of Technical Analysis. *Journal of Financial and Quantitative
   Analysis*, 48(5), 1433–1461. https://doi.org/10.1017/S0022109013000586
   — 기술적 분석 효과는 초대형주에서 최약 (유니버스에서 초대형주 제외 근거)
3. Park, C.-H., & Irwin, S. H. (2007). What Do We Know About the Profitability
   of Technical Analysis? *Journal of Economic Surveys*, 21(4), 786–826.
   https://doi.org/10.1111/j.1467-6419.2007.00519.x
   — 거래비용·데이터 스누핑 경고 (유동성 상위 종목만 스캔하는 근거)
4. Jegadeesh, N., & Titman, S. (1993). Returns to Buying Winners and Selling
   Losers: Implications for Stock Market Efficiency. *The Journal of Finance*,
   48(1), 65–91. https://doi.org/10.1111/j.1540-6261.1993.tb04702.x
   — 모멘텀/상대강도 효과 (와인스타인 RS 가점의 학술 근거)
5. Bulkowski, T. N. (2005). *Encyclopedia of Chart Patterns* (2nd ed.). Wiley.
   — busted 패턴 정의, 5% 룰, 되돌림(throwback) 통계, 삼각형 돌파는 꼭짓점
   거리의 평균 73~75% 지점 (H&S·삼각수렴 탈락 기준)
6. O'Neil, W. J. (2009). *How to Make Money in Stocks* (4th ed.). McGraw-Hill.
   (초판 1988) — 컵앤핸들 정의, 핸들은 컵 상반부, 매수는 피벗 +5% 이내
7. Weinstein, S. (1988). *Secrets for Profiting in Bull and Bear Markets*.
   Dow Jones-Irwin. — 4단계 사이클, 30주선 매매 규칙, 돌파 거래량 기준
