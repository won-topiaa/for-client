# TikTok Lite 포인트 파머 (AutoX.js)

TikTok Lite에서 **시청 → 타이머 수령 → 광고보기 → 좋아요 수령 → 출석체크**를
자동으로 반복해 포인트를 적립하는 안드로이드 자동화 앱입니다.
플로팅 제어판의 **[시작]** 한 번으로 동작하며, 켜두면 알아서 포인트를 쌓습니다.

> ⚠️ **개인 편의용 자동화입니다.** TikTok 이용약관상 자동화가 제한될 수 있으며,
> 계정 정지·포인트 회수 등의 위험이 있습니다. **판매·사용 전 반드시
> [`구매전_필독.md`](./구매전_필독.md)(고지 및 면책 동의서)를 읽고 구매자에게 동의를
> 받으세요.**

## 제품 구성

| 파일 | 역할 |
|------|------|
| `main.js` | 진입점 — 플로팅 제어판(시작/정지/좌표설정) |
| `core.js` | 자동화 엔진 — 플로우, 오류 복구, 무한 파밍 루프, 좌표 캘리브레이션 |
| `config.js` | 설정 — 기기 저장소에 영구 저장(좌표설정 결과 자동 저장) |
| `project.json` | APK 빌드 descriptor(앱 이름/패키지/권한) |

## 주요 기능

- **원클릭 실행**: 제어판 [시작] 버튼 하나로 전체 플로우 자동 진행
- **무한 파밍 모드**: 영상 시청으로 타이머를 충전하며 20분마다 수령을 반복 → 켜두면 계속 적립
- **자동 복구**: 앱이 튕기거나 다른 화면으로 벗어나면 자동으로 재실행/복귀
- **탭 좌표설정**: [좌표설정] 버튼 → 화면을 탭하는 것만으로 버튼 위치 등록(픽셀 계산 불필요)
- **설정 영구 저장**: 좌표/옵션이 기기에 저장되어 재실행해도 유지
- **로그 기록**: 화면 로그 + `/sdcard/ttl_farmer.log` 파일로 문제 추적

## 동작 흐름 (최종 플로우 — 원클릭)

```
[시작]
 1. TikTok Lite 실행
 2. 영상화면 팝업(출석/이벤트) 종료 — '14일 연속 출석' 팝업은 ✕로만 닫음(출석은 마지막에)
 3. 포인트 페이지 → 타이머 1회 수령(시작분) → 매일광고 '시작 방문'(열리는 만큼 자동)
 4. 첫 영상 좋아요 → 영상 시청만 꾸준히
    · 시청 총 시간: 60~100분 사이 랜덤(매번 다름 — 봇 티 방지)
    · 영상 1개당: 랜덤(15% 빨리넘김/75% 보통/10% 오래봄) / 피드 '광고' 영상은 즉시 넘김
    · 팝업·게임광고는 감지 즉시 닫고 지나감, 중간에 포인트 페이지 안 감
 5. (시간 종료) 포인트 페이지 1회 진입:
    타이머(종료분) → 좋아요 포인트 받기 → 출석체크 → 매일광고 '마무리 방문'
    → 광고 추가보상 1회 → 출석 재확인(보험)
 6. TikTok Lite 앱 종료
```
> 시청 시간 범위는 `config.timing.watchMinMs/watchMaxMs`(기본 60~100분)로 조절.
> 시간이 다 되면 자동으로 수확·출석 후 앱을 종료합니다. [정지]/볼륨(-)로 중단하면 마무리 생략.
> 20분마다 수확하는 예전 방식은 `config.harvestEveryCycle: true`로 되살릴 수 있음(기본 꺼짐).

**자동 수령 대상 (게임 아닌 것만):**
- ✅ 출석하기 (하루 1회 — 1차 + 재확인 2중으로 반드시 수행)
- ✅ 20분 타이머 → 포인트 받기 (시작·종료 각 1회 — '광고 보기' 팝업 광고 포함)
- ✅ **매일 광고 시청 — 시작·마무리 2번 방문**, 방문당 열리는 만큼(한도 일부러 안 채움)
- ✅ '광고 보면 추가 보상' 1회 (마무리)
- ✅ 1개 영상 좋아요 → 포인트 받기

**의도적으로 건드리지 않는 것 (게임/상호작용/탐지위험):**
- ❌ 캔디병 채우기, 킥오프 슛, 럭키 스핀, 원판 돌리기 (미니게임)
- ❌ 친구 QR 초대, 팀 이뤄 받기 (친구/QR 필요)
- ❌ 12회 검색, 매일 게시 (타이핑/업로드 필요)

> 이 4가지만으로도 매일 꾸준히 포인트가 쌓이며, 게임류는 UI가 자주 바뀌어
> 유지보수 부담·오작동·탐지 위험이 커서 제외했습니다.

## 설치 & 최초 설정 (구매자용)

### 1) AutoX.js 설치 & 권한
- AutoX.js 설치
- **접근성 서비스 ON**: 설정 → 접근성 → AutoX.js → 사용
- **다른 앱 위에 표시(오버레이) ON**: 설정 → 앱 → AutoX.js → 다른 앱 위에 표시 허용

### 2) 스크립트 넣고 실행
- `main.js`, `core.js`, `config.js`, `project.json`을 AutoX.js 프로젝트 폴더에 넣기
- `main.js` 실행 → 화면에 제어판이 뜸

### 3) 좌표설정 (최초 1회) — v2에선 딱 2곳만!
대부분의 버튼(출석하기·받기·확인·광고보기·타이머)은 **한글 텍스트로 자동 인식**하므로,
좌표는 아래 2곳만 잡으면 됩니다:
- 제어판 **[좌표설정]** 누르기 → 안내대로 탭
  - ① **리워드(포인트) 페이지 여는 탭** (보통 좌측 하단)
  - ② **광고 화면 닫기 X** (보통 우측 상단)
- 완료되면 자동 저장됨

### 4) 시작
- **[시작]** 누르면 파밍 시작. 폰을 켜둔 채 두면 계속 적립됩니다.
- 멈추려면 **[정지]**.

## 원클릭 / 앱 형태로 배포

- **홈 화면 바로가기**: AutoX.js에서 스크립트 길게 눌러 "바로가기 생성" → 홈 아이콘 1탭 실행
- **독립 APK**: AutoX.js "APK 빌드"로 `project.json` 기반 독립 앱 생성(앱 이름/아이콘 지정 가능) → 구매자에게 APK만 전달

## 설정 커스터마이즈 (`config.js`)

| 항목 | 설명 |
|------|------|
| `mode` | `"farm"`(무한 파밍, 기본) / `"once"`(1~12 한 바퀴 후 종료) |
| `timing.betweenCycleMs` | 타이머 수령 간격(기본 20분) |
| `timing.scrollIntervalMs` | 영상 1개당 시청 시간(기본 20초) |
| `timing.afterAdWatch` | 광고 후 대기(기본 30초) |
| `humanize` | 대기시간에 랜덤 부여(사람처럼) |
| `texts.*` | 폰 언어에 맞는 버튼 문구 후보 |

## 문제 해결

- **버튼이 엉뚱한 곳을 누름** → [좌표설정] 다시 진행
- **텍스트 못 찾음** → `config.js`의 `texts`에 실제 화면 문구 추가
- **앱이 안 켜짐** → `appName` / `packageCandidates` 확인
- **광고가 30초보다 김** → `timing.afterAdWatch` 늘리기
- **화면 꺼짐** → `keepScreenOn: true`(기본) 유지, 절전 예외 등록 권장
- 상세 로그: `/sdcard/ttl_farmer.log`

## ✅ 실기기 검증 결과 (2026-07-04, Galaxy Z Flip3 / One UI 6.1.1 / Android 14)

실제 기기(TikTok Lite 리워드 페이지)에서 **adb로 각 리워드를 직접 눌러** 확인했습니다.
문구/좌표는 이 기기 기준 실측이며, 계정·버전에 따라 다를 수 있습니다.

| 리워드 | 실제 버튼/문구 | 검증 결과 |
|--------|----------------|-----------|
| 20분 타이머 | `20분마다 타이머 누르고 최대 40 받기` → **`포인트 받기`** | ✅ 탭 → **+4P 적립**(토스트 + 카운트다운 전환 확인) |
| 매일 광고 | `매일 광고를 시청하여 최대 200 받기` → **`시청`** (개당 30초·5P, 하루 40개) | ✅ 광고 열림 → 30초 시청 → X 닫기 → **+5P 적립** |
| 좋아요 미션 | 피드 우측 하트 + `포인트 받기` | ✅ `feedLike` 좌표(0.92, 0.57)가 하트를 정확히 누름(**102→103**, 복구). 오늘 미션 완료라 수령은 타이머와 동일 경로 |
| 출석 | **`오늘 출석하고 N 받기`**(활성) / `내일 출석하고 N 받기`(회색) | ⏳ 버튼 문구·clickable/enabled 상태 dump 확인. 오늘분 완료라 **활성 버튼 실수령은 자정 후 검증 예정** |
| 라이브 | `라이브 영상 시청하고 최대 60 받기` → `시청` → `수령` → `리워드 포인트 수령` | ⚠️ 지급은 확인(**0→2회, ~4P/회**)했으나 라이브 UI가 **접근성 미노출**(자동화 불가) + 선물 버튼 인접 → **기본 꺼둠(`liveBatch=0`)** |
| 스크롤 | — | ✅ 최상단↔최하단 안정, 맨 위 복귀 정상 |

### 이번 검증으로 고친 것
- **광고 보상 손실 버그**: 광고 크레딧은 30초 후 지급되는데 코드가 20초에 X를 눌러 무보상이던 것 → **적립 표식이 사라질 때까지 기다린 뒤 닫도록** 수정(`closeAd`).
- **광고 오탐**: `adMarker`(`시청하고`)가 리워드 페이지의 `라이브 영상 시청하고`까지 잡던 것 → **광고 화면 전용 문구**(`시청하고 5포인트`/`초 시청하고`)로 좁힘.
- **출석 미수령**: 이 UI엔 `출석하기`가 없고 `오늘 출석하고 N 받기` 버튼(자동 아님) → `attendance` 문구 + **부분매칭**(`exact=false`)으로 수정. 회색 `내일 출석하고…`·카드 제목과는 안 겹침.
- **`dailyAdBatch` 6→5**: 하루 40개 ÷ 한 런 ~8사이클 = 균등 분산(봇 티↓). 짧게 돌리면 6~8로.
- **라이브 안전화**: 켜더라도 fail-safe(수령 텍스트 못 찾으면 no-op, **선물 버튼 절대 안 누름**, 앱 종료 방지). 지급 자체는 안 되니 기본은 꺼둠.

### 이 계정 UI 특이사항(참고)
- `광고 보면 추가 보상`·`출석하기` 카드/버튼은 이 버전(**복귀 사용자 프로모**)엔 없음.
- **게임 카드가 페이지 상단**에 위치(원판/슈팅마블/돼지저금통/킥오프/캔디병) — `gameTitle`/`gameButton` 차단으로 안전.
- 보상 금액은 계정/프로모마다 다름(게임의 ₩ 수만원 표기는 프로모용 부풀린 값).
