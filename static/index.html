📈 이평선 레이더

일봉·주봉·월봉에서 주요 지지/저항 역할을 해온 이동평균선을 백테스트로 찾아드립니다.

어떤 이동평균선이 이 종목의 지지/저항으로 실제 작동해 왔는지, 과거 데이터를 백테스트해 순위로 보여드립니다.

일봉·주봉·월봉 각각에서 가장 믿을 만한 2~3개 선을 추천하고, 차트 위에 지지·저항·돌파 사건을 표시합니다.

기간 0 = 상장 후 전체 기간 · 추천 기본값: 일봉 3년, 주봉 7년, 월봉 전체 (최근 흐름에 자동 가중)

🇺🇸 미국 대표
▲ 지지 성공 (반등) ▼ 저항 성공 (하락) ● 지지 이탈 (아래로 뚫림) ● 저항 돌파 (위로 뚫음)

전체 후보 이평선 성적표

★ = 추천 · 최근 사건에 가중치를 준 성공률 기준
이평선터치지지성공저항성공 돌파(실패)미확정성공률*점수최근 터치
* 성공률은 최근 사건에 더 큰 가중치를 준 가중 성공률입니다. 점수 = 성공률 신뢰하한 × log(1+가중 성공 횟수) — "자주 그리고 믿을 만하게" 지지/저항이 된 순서.

스캔 대상 — 🇰🇷 국내: 거래대금 상위 300개 종목 (시가총액 상위 30개 초대형주 제외 · 관련 연구상 초대형주에서 기술적 분석 효과가 가장 약하기 때문) · 🇺🇸 미국: S&P500 구성종목 중 메가캡 제외 · 스캔 시점의 최신 상장목록 기준으로 자동 갱신 · 결과 30분 캐시.
패턴 탐지는 규칙 기반 자동 분석이며 미완성/실패 가능성이 있는 형태도 포함됩니다.
패턴을 이탈·무효화한 종목은 자동 탈락합니다 — 각 패턴 설명의 "자동 탈락" 기준(연구 문헌 기반)에 걸리면 다음 스캔(최대 30분)에서 목록에서 빠집니다.
