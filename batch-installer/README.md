# 배치 인스톨러 (Batch Installer) — 초안 v0.1

여러 앱을 **원클릭으로 순서대로 구글플레이스토어에서 자동 검색·설치**해 주는
AutoX.js 앱입니다. (틱톡 파머와 동일한 접근성 자동화 방식)

---

## 무엇을 하는가

1. 그룹별로 앱 목록을 관리 (앱 안에서 **수시로 편집·저장** 가능)
2. **전체 선택 / 부분 선택**(체크박스)
3. 그룹의 **[⬇ 다운로드]** 또는 상단 **[⬇ 선택 전체설치]** 를 누르면
4. 선택된 앱을 **하나씩 순서대로** 플레이스토어에서 검색 → 상단 결과 진입 →
   **[설치] 버튼을 자동으로 탭** → 설치 완료 감지 → 다음 앱 진행
5. 이미 최신이면 건너뛰고, 업데이트가 있으면 업데이트, 호환 안 되면 건너뜀

## 무엇을 못 하는가 (중요 — 손님께 미리 고지)

- **완전 무음(화면조차 안 뜨는) 백그라운드 설치는 불가능**합니다.
  안드로이드 정책상 일반 갤럭시폰에서는 루팅/기업용 MDM 없이는
  타사 앱을 조용히 설치할 수 없습니다.
- 이 앱은 **플레이스토어 화면을 자동으로 조작**해서 사람이 손을 대지 않아도
  진행되게 합니다. (플레이스토어가 화면에 뜨는 건 정상 동작)
- 접근성 자동조작 특성상 **구글플레이 정식 출시는 권장하지 않고**,
  기존 제품처럼 **APK 직접 배포(사이드로드)** 방식이 맞습니다.

## 필요 권한

| 권한 | 용도 | 필수 |
|---|---|---|
| 접근성(Accessibility) 서비스 | [설치] 버튼 자동 클릭 | ✅ 필수 |
| 다른 앱 위에 표시(오버레이) | (선택) 진행 중 제어 | 선택 |

## 사용법

1. AutoX.js에서 이 폴더를 프로젝트로 열고 실행(또는 APK 빌드해 설치)
2. AutoX.js **접근성 서비스 ON**
3. 목록에서 설치할 앱 체크 → **[⬇ 다운로드]**
4. 확인창에서 [확인] → **화면에서 손 떼고 지켜보기**

## 목록 편집

- **＋그룹** : 새 그룹 추가
- 그룹의 **＋앱** : 앱 추가 — `이름` 또는 `이름|패키지명` 형식
  - 패키지명을 넣으면 검색을 건너뛰고 해당 앱으로 바로 이동(더 정확)
  - 예) `연합뉴스|com.yonhapnews.andrapp`
- 그룹의 **편집** : 그룹 이름 변경(비우고 확인 시 그룹 삭제)
- 앱 오른쪽 **🗑** : 앱 삭제
- **💾저장** : 편집한 목록을 기기에 저장(다음 실행 때 유지)
- **공장초기화** : 기본 목록(config.js)으로 되돌림

## 기본 목록

`config.js`의 `defaultGroups`에서 공장 초기값을 바꿀 수 있습니다.
현재 테스트용으로 **연합뉴스 / 조선일보 / 공영쇼핑** + 예시 그룹이 들어 있습니다.

## 튜닝 포인트 (실기기 테스트 시)

플레이스토어 UI는 기기/버전/언어에 따라 조금씩 다릅니다. 안 맞으면
`config.js`에서만 조정하세요:
- `labels` : 버튼 글자(설치/업데이트/열기 등) — 기기 언어에 맞게
- `timing` : 화면 전환 대기 시간(느린 기기면 늘리기)

앱 이름 검색이 부정확하면 해당 앱에 **패키지명(pkg)** 을 넣어주는 것이
가장 확실합니다.

### 파일 구성

| 파일 | 역할 |
|---|---|
| `main.js` | 화면(UI) · 목록 편집 · 설치 시작 |
| `core.js` | 설치 엔진(플레이스토어 자동 조작) |
| `config.js` | 기본 목록 · 타이밍 · 버튼 라벨 |
| `project.json` | AutoX.js 프로젝트 설정 |
