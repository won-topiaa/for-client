# 📈 이평선 레이더 (stock-ma-analyzer)

종목을 검색하고 **분석** 버튼을 누르면, **일봉·주봉·월봉**별로 그동안 **가장 자주,
믿을 만하게 지지/저항 역할을 해온 이동평균선을 2~3개씩** 백테스트로 찾아
차트에 그려주는 웹 프로그램입니다.

- 토스증권 Open API 연동 (키가 없으면 합성 샘플 데이터로 즉시 체험 가능)
- 후보 이평선: 일봉 `5/10/20/50/60/100/120/200/240`, 주봉 `5/10/20/30/52/60/104`, 월봉 `3/6/12/24/36/60` (설정 변경 가능)
- 추천 이평선을 캔들차트 위에 오버레이 + 지지/저항 이벤트 마커 표시
- 전체 후보의 성적표(터치·지지성공·저항성공·돌파·성공률·점수) 제공

> ⚠️ 과거 데이터 통계이며 투자 권유가 아닙니다. 과거에 잘 지켜진 이평선이
> 미래에도 지켜진다는 보장은 없습니다.

---

## 1. 빠른 시작 (API 키 없이)

```bash
cd stock-ma-analyzer
pip install -r requirements.txt
python -m uvicorn app.server:app --port 8000
# 브라우저에서 http://localhost:8000 접속
```

키가 없으면 자동으로 **샘플 데이터 모드**(시드 고정 합성 데이터)로 실행됩니다.
UI·분석 로직을 그대로 체험할 수 있습니다.

실제 CSV 데이터가 있다면 `data/종목코드.csv` 로 넣으면 샘플 모드에서도 그대로 분석됩니다.
(컬럼: `date,open,high,low,close,volume`)

## 2. 토스증권 Open API 연결

1. [토스증권 Open API](https://corp.tossinvest.com/ko/open-api) 에서 사용 신청 후
   `client_id` / `client_secret` 발급
2. 설정 방법 (둘 중 하나):
   - 환경변수: `TOSS_CLIENT_ID=... TOSS_CLIENT_SECRET=... python -m uvicorn app.server:app`
   - 또는 `config.example.json` 을 `config.json` 으로 복사해 키 입력
3. 키가 감지되면 자동으로 토스 공급자로 전환됩니다 (`provider: "toss"` 로 강제 가능).

### 공식 스펙 반영 상태

토스증권 공식 OpenAPI 스펙(v1.1.5) 기준으로 기본값이 맞춰져 있습니다:

- 토큰: `POST /oauth2/token` (form, client_credentials)
- 캔들: `GET /api/v1/candles?symbol=&interval=1d&count=&before=`
  (1회 최대 200개, `nextBefore` 커서로 과거 페이지네이션, 수정주가 기본 적용)
- 종목 정보: `GET /api/v1/stocks?symbols=005930,AAPL`

알아둘 것 두 가지:

1. **공식 API 에는 "이름 검색"이 없습니다** (`/api/v1/stocks` 는 코드 전용).
   그래서 이름 검색은 내장 주요 종목 사전(약 90개, `app/providers/kr_symbols.py`)
   으로 코드를 찾은 뒤 API 로 실제 종목명을 확정합니다. 사전에 없는 종목은
   **6자리 코드**(예: `042670`)나 **미국 티커**(예: `AAPL`)를 직접 입력하세요.
   전 종목 이름 검색을 원하면 KRX 정보데이터시스템(data.krx.co.kr)에서 상장종목
   목록을 받아 `data/symbols.csv` (컬럼: `symbol,name[,market]`)로 저장하면
   자동으로 검색에 포함됩니다.
2. **봉 단위는 분봉/일봉만 제공**됩니다. 주봉·월봉은 일봉을 자동으로
   리샘플링(주: 월~금 집계, 월: 월별 집계)해서 분석합니다.

스펙이 향후 바뀌면 `config.json` 의 `toss` 섹션에서 경로·파라미터명을
재정의할 수 있고, 응답 파싱은 필드명 별칭 기반(관용 파서)이라 구조가 조금
달라져도 대부분 자동으로 해석됩니다. 예전 버전 `config.json` 의 기본값
(`/api/v1/market/candles` 등)은 실행 시 자동으로 새 스펙으로 이관됩니다.

## 3. 백테스트 기간 — 무엇을 권장하나

**전체 기간보다는 "타임프레임별로 다른 기간 + 최근 가중"을 권장하며, 그렇게 기본값을 설정했습니다.**

| 타임프레임 | 기본값 | 근거 |
|---|---|---|
| 일봉 | **최근 3년** | 이평선 지지/저항은 그 종목을 매매하는 참여자 구성(수급 레짐)의 산물이라 영구적이지 않습니다. 10년 전 데이터까지 동일 가중으로 섞으면 지금은 무의미한 레짐의 통계가 노이즈로 들어옵니다. 3년(약 750봉)이면 MA240까지 충분한 표본이 나오면서도 현재 레짐 위주로 측정됩니다. |
| 주봉 | **최근 7년** | 주봉은 봉 수가 적어(1년 = 52개) 3년으로는 MA104 같은 장기선의 터치 표본이 부족합니다. 7년(약 364봉)이면 표본과 최신성의 균형이 좋습니다. |
| 월봉 | **전체 기간** | 월봉은 20년 치가 있어도 240개뿐입니다. 자르면 장기선 통계가 불가능하므로 전체를 쓰는 것이 맞습니다. |

여기에 더해 모든 타임프레임에서 **최근 가중(지수 반감기)** 을 적용합니다.
분석 구간의 1/3을 반감기로 하여 최근 사건이 오래된 사건보다 큰 가중치를
받습니다. 즉 "전체 기간을 쓰되 옛날 데이터의 발언권을 줄이는" 절충이
월봉에 자동 적용되고, 일봉·주봉도 구간 내에서 최신 흐름이 우선됩니다.

UI에서 기간을 자유롭게 바꿀 수 있고, **0을 입력하면 전체 기간**으로 돌립니다.
상장한 지 얼마 안 된 종목은 데이터가 짧아 장기선이 "데이터 부족"으로 표시될
수 있습니다 (그 자체가 유의미한 정보입니다).

## 4. 분석 방법 (알고리즘)

차트에 그려진 단순이동평균(SMA)과 가격의 상호작용을 다음 규칙으로 측정합니다.

1. **터치**: 봉의 저가~고가 범위가 MA 주변 허용 밴드에 닿으면 터치.
   밴드 폭은 `max(ATR(14) × 0.5, 종가 × 0.15%)` — 종목 변동성에 자동 적응.
2. **에피소드**: 2봉 이내 연속 터치는 하나의 사건으로 묶음 (한 번의 눌림을
   여러 번으로 중복 집계하지 않기 위함).
3. **방향**: 직전 5봉 종가가 MA 위였으면 "지지 시험", 아래였으면 "저항 시험".
4. **판정** (에피소드 시작 후 일봉 10봉 / 주봉 8봉 / 월봉 6봉 안에):
   - **성공(반등)**: 종가가 MA에서 원래 방향으로 ATR×1.0 이상 되돌아감
   - **실패(돌파)**: 종가가 MA 반대편으로 ATR×1.0 이상 넘거나, 3봉 연속으로
     터치 밴드 **바깥** 반대편에서 마감 (밴드 안에서 MA 를 사이에 두고
     오르내리는 노이즈는 돌파로 치지 않음)
   - 어느 쪽도 아니면 **미확정** (성공률 계산에서 제외)
5. **점수** = `가중 성공률의 Wilson 신뢰하한 × log(1 + 가중 성공 횟수)`
   - Wilson 신뢰하한: "3번 중 3번 성공(100%)"이 "20번 중 15번 성공(75%)"을
     이기지 못하게 표본 크기를 반영
   - log 항: 자주 작동한 이평선에 가점하되 횟수가 질을 압도하지 않게 압축
6. **추천**: 점수순 상위에서, 기간이 20% 이내로 비슷한 이평선(예: 100과 120)은
   상위 하나만 남기고 2~3개 선정. 최소 터치 횟수(일 5·주 4·월 3) 미달이면
   "표본 부족" 표시와 함께 참고용으로만 노출.

미래 참조(lookahead) 없음 — 판정은 해당 사건 이후의 봉만 봅니다.

## 5. 프로젝트 구조

```
stock-ma-analyzer/
├── app/
│   ├── analysis.py      # 핵심 백테스트 엔진 (터치/판정/점수)
│   ├── service.py       # 데이터 취득 → 분석 → JSON 직렬화
│   ├── server.py        # FastAPI (검색/분석 API + 정적 서빙)
│   ├── config.py        # 설정 로딩 (env > config.json > 기본값)
│   ├── resample.py      # 일봉 → 주봉/월봉
│   └── providers/
│       ├── toss.py      # 토스증권 Open API 클라이언트 (설정 주도)
│       └── sample.py    # 합성 데이터 + data/*.csv 공급자
├── static/              # 프런트엔드 (lightweight-charts v5 vendored)
├── tests/               # pytest 스위트
├── data/                # (선택) 실제 CSV 데이터 넣는 곳
└── config.example.json
```

## 6. 사이트로 배포 (Render — 무료, GitHub 푸시 시 자동 업데이트)

로컬 실행 대신 웹사이트로 쓰려면 [Render](https://render.com) 무료 플랜으로
배포할 수 있습니다. 저장소 루트에 `render.yaml` 이 준비되어 있습니다.

1. render.com 가입 (GitHub 계정으로 로그인)
2. **New → Blueprint** → 이 GitHub 저장소 연결 → 브랜치 선택
3. 환경변수 3개 입력:
   - `TOSS_CLIENT_ID` / `TOSS_CLIENT_SECRET`: 토스 API 키
   - `SITE_PASSWORD`: 사이트 접속 비밀번호 (설정하면 접속 시 비밀번호를
     물어봅니다 — **본인 API 키로 도는 사이트이므로 반드시 설정 권장**)
4. 배포가 끝나면 `https://ma-radar-xxxx.onrender.com` 형태의 주소가 생깁니다
5. **중요 — 토스 허용 IP 등록**: Render 대시보드 → 해당 서비스 →
   우측 상단 **Connect → Outbound** 에 나오는 고정 IP 3개를
   토스증권 Open API 설정의 "허용 IP 관리"에 모두 추가
6. 이후에는 이 저장소 브랜치에 푸시할 때마다 **자동으로 재배포**됩니다

무료 플랜 특성: 15분 동안 접속이 없으면 잠들었다가 다음 접속 때 깨어나는 데
30초~1분 걸립니다. 실제 API 호출은 10분 캐시로 보호되어 여러 번 눌러도
토스 요청 한도를 아끼며, 동시에 같은 종목을 조회해도 호출은 1번만 나갑니다.

API 통합까지 검증합니다.
