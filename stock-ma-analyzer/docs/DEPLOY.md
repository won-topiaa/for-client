# 배포 가이드 — 회원 계정 영구 저장(무료)

'오늘의 지지선 터치'는 회원 전용이에요. 회원 계정을 **영구히** 보관하려면
무료 외부 PostgreSQL을 붙이면 됩니다. (안 붙이면 Render 무료 플랜에서
인스턴스가 잠들거나 재배포될 때 **가입한 계정이 전부 사라져요.**)

여기서는 **Neon**을 씁니다 — 신용카드 없이 무료이고, 만료 없이 계속 유지돼요.

---

## 1. Neon 무료 Postgres 만들기 (약 3분)

1. https://neon.tech 접속 → **Sign up** (GitHub 계정으로 가입하면 편해요).
2. **Create project** 클릭 → 이름은 아무거나(예: `wontopia`), 지역은
   `Asia`에 가까운 것(없으면 기본값)으로 두고 생성.
3. 생성되면 **Connection string**(연결 문자열)이 보여요. `psql` 또는
   `Connection string` 탭에서 **`postgresql://...` 로 시작하는 한 줄**을 복사.
   - 예: `postgresql://myuser:AbCd1234@ep-cool-name.ap-southeast-1.aws.neon.tech/neondb?sslmode=require`
   - ⚠️ 이 문자열에는 비밀번호가 들어 있으니 **절대 코드/깃허브에 올리지 마세요.**
     (Render 환경변수로만 넣습니다. 아래 2번.)

> 연결 문자열이 `?sslmode=require` 로 끝나는지 확인하세요. Neon은 SSL이
> 필수라 보통 자동으로 붙어 있어요. 없으면 끝에 `?sslmode=require`를 붙이면 됩니다.
>
> Neon이 **Pooled**(풀러)와 **Direct**(직접) 연결 문자열 두 가지를 보여줄 수
> 있는데, **둘 다 그대로 써도 됩니다.** (앱이 풀러 호환 모드로 동작합니다.)

---

## 2. Render에 연결 문자열 넣기

1. Render 대시보드 → 이 서비스(`ma-radar`) → **Environment** 탭.
2. **Add Environment Variable**:
   - **Key**: `DATABASE_URL`
   - **Value**: 1번에서 복사한 `postgresql://...` 문자열 붙여넣기
3. **Save Changes** → 자동으로 재배포돼요.

이제부터 가입한 회원은 Neon DB에 저장돼서, 재배포하거나 서버가 잠들었다
깨어나도 **계정이 그대로 유지됩니다.**

> 코드는 손댈 필요 없어요. `DATABASE_URL`이 있으면 자동으로 Postgres를,
> 없으면 SQLite(임시)를 씁니다. 같은 코드가 둘 다 지원해요.

---

## 3. (선택) 사이트 전체 비밀번호

아직 공개하기 전이라 **아무나 못 들어오게** 막고 싶으면:
- Render Environment에 `SITE_PASSWORD` = 원하는 비밀번호 추가.
- 그러면 사이트 전체가 브라우저 기본 로그인 창으로 잠겨요(아이디는 아무거나).
- 공개할 때는 이 값을 지우면 됩니다.

---

## 4. 잘 됐는지 확인

1. 사이트 열기 → `/touches` (오늘의 터치) 들어가면 로그인 페이지로 넘어가는지.
2. 이메일로 **가입** → 터치 화면이 열리는지.
3. Render에서 **Manual Deploy → Clear build cache & deploy** 로 재배포한 뒤,
   다시 그 이메일로 **로그인**이 되는지 (= 계정이 유지됐는지).
   - 로그인되면 Postgres 영구 저장이 정상 동작하는 거예요. 🎉

## 참고: 개인정보

이메일로 회원을 받으면 **개인정보 수집**에 해당해요(한국 개인정보보호법/PIPA).
- 사이트에 **개인정보처리방침**을 두었습니다: `/privacy`
- 가입 화면에서 이 방침에 **동의**를 받도록 되어 있어요.
- 수집 항목은 **이메일과 비밀번호(해시)뿐**이고, 마케팅·제3자 제공은 없습니다.
- 문의/삭제 요청 창구 이메일은 소개 페이지(`/about`)의 주소를 씁니다.
