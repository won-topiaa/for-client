## 알려진 구멍

**`refreshAtKst` 가 문구에만 적용돼 있다.**

- `components/TodayBrief.tsx` — 서버가 준 `refreshAtKst` 로 **문구**를 그린다
- `pages/watchlist.tsx` — `env.ts` 의 `SCREENER_REFRESH_HOUR_KST/MIN` (하드코딩 06:30)
  으로 **'오늘 지지선' 배지의 오늘/어제 경계를 계산**한다

서버의 `DAILY_REFRESH_KST` 를 바꾸면 **카드는 새 시각을 말하는데 배지는 옛 경계로
계산**한다. 둘 중 하나만 틀린 것보다 나쁘다 — 화면끼리 말이 안 맞는다.

지금 당장은 두 값이 같아서(06:30) 아무 일도 일어나지 않는다. 갱신 시각을 바꿀
일이 생기면 **바꾸기 전에** `watchlist.tsx` 를 `refreshAtKst` 기반으로 고친다.
아니면 `env.ts` 의 두 상수를 지우고 경계 계산도 서버 값을 쓰게 한다(이쪽이 낫다).
